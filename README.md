# AFTER DARK 🌹
> A Private Sensual Couples' Dare Game for Two

AFTER DARK is an intimate, private dare game designed exclusively for consenting adults in a relationship. Explore desires, ignite passion, and deepen connection through mysterious clickable dare cards across three escalating levels of intensity.

---

## ✨ Features

- **3 Escalating Levels**:
  - **Level 1 — Romantic & Sensual**: Gentle, teasing, playful intimacy.
  - **Level 2 — Passion & Intimacy**: Bolder sensations and spicy surprises.
  - **Level 3 — Extreme Intimacy**: Deep, adventurous, and passionate exploration.
- **Frosted Mystery Cards**: Dares remain blurred and concealed until tapped.
- **Random Dare Engine**: Never repeats the same dare in a round.
- **Interactive Timer**: Built-in countdown ring with Start / Pause / Reset for timed challenges.
- **The Lovers' Pact**: Playful, witty, and intimate agreement between partners.
- **Custom Dare Studio ("My Dares")**: Create, edit, preview, and delete personalized dares.
- **Full Offline Persistence**: All progress and custom dares saved in `localStorage`.
- **Mobile-First & Sensual Aesthetic**: Deep burgundy, wine, and champagne gold with glassmorphism and floating rose petals.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: SCSS (Modern Compiler) + CSS Variables + Glassmorphism
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Hosting**: Vercel ready

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/gkkv-ai/lets-play-dark-game.git

# Navigate to project folder
cd lets-play-dark-game

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

## 🔒 Privacy & Consent

This application runs 100% locally in the browser with zero backend data collection. All progress, custom dares, and settings are saved strictly on your local device. Either partner can pause, skip, or stop at any time.
